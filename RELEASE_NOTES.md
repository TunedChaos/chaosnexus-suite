# ChaosNexus Suite 0.8.5 (prerelease)

All-in-one desktop package: **Forge** + supervised **Anvil** + **Codex** + **Crucible** + slim **Scripts**.

## Downloads

Prefer **Codeberg** as the canonical host:

https://codeberg.org/TunedChaos/chaosnexus-suite/releases

GitHub Releases mirror the same assets when present.

## Models (Path 2)

GGUF weights are **not** inside the installer. After install, open **Settings → Models**, accept the license checkbox, and download **ChaosNexus Tuned v1** (`TunedChaos/ChaosNexus_Tuned_v1-GGUF` / `ChaosNexus_Tuned_v1-Q4_K_M.gguf`), or choose a local `.gguf`.
