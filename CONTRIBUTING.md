# Contributing

Open issues and pull requests on **Codeberg**: [TunedChaos/chaosnexus-suite](https://codeberg.org/TunedChaos/chaosnexus-suite).

This repository is packaging-only. Component changes belong in the corresponding Codeberg polyrepos (Forge, Anvil, Codex, Crucible, Scripts). Maintainers sync from the sibling component checkouts.

GitHub pull requests on the mirror are not accepted.
