# Contributing

GitHub is the primary public host. Open issues and pull requests on **GitHub**: [TunedChaos/chaosnexus-suite](https://github.com/TunedChaos/chaosnexus-suite).

## Issues

File **all** public bugs and feature requests on this repository ([TunedChaos/chaosnexus-suite](https://github.com/TunedChaos/chaosnexus-suite/issues)).

Other ChaosNexus GitHub repos have Issues disabled - use the issue forms here and pick the **Component** (forge, anvil, codex, …). Triage applies matching labels.

This repository is packaging-only. Component changes belong in the corresponding GitHub repositories (Forge, Anvil, Codex, Crucible, Scripts). Maintainers sync from the sibling component checkouts.

Support the project: [github.com/sponsors/TunedChaos](https://github.com/sponsors/TunedChaos).
